# 오광첩 (Okwangcheop)

사토 기준 로또 6/45 번호 생성기 — Galaxy용 PWA

## Galaxy에서 앱처럼 사용하기

1. GitHub Pages 활성화 (저장소 → Pages → main / root)
2. 페이지 주소를 Samsung Internet 또는 Chrome에서 열기
3. 메뉴 → **홈 화면에 추가** / **앱 설치**
4. 홈 화면에 오광첩 아이콘이 생깁니다.

## 기능

- 그 주 토요일 20:35 기준 달/우주/태양 번호
- 달력 기준 번호
- 진짜 무작위 번호 (다시 뽑기)
- 당첨 등수 확인
- 무작위 로또 사기 좋은 날 추천
- 연금복권720+ 안내
